# Ride Reader

Rapido कैप्टन की स्क्रीन पर आई राइड को बोलकर सुनाने वाली ऐप.

## क्या करती है
- नई राइड आते ही पिकअप का नाम, फिर किलोमीटर, फिर ड्रॉप का नाम और किलोमीटर बोलती है.
- एक साथ कई राइड आएँ तो पहली पूरी बोलने के बाद ही दूसरी बोलती है.
- जो एरिया आपने बंद किए हैं, उसकी राइड पर सबसे पहले बोलती है "यह एरिया आपके लिए सही नहीं है" और बाकी नहीं पढ़ती.
- राइड स्क्रीन से हट जाए तो लाइन से निकाल देती है, पुरानी राइड नहीं बोलती.
- यह कुछ क्लिक या accept नहीं करती. इसमें INTERNET permission भी नहीं है.

## GitHub से APK बनाना (लैपटॉप पर कुछ इंस्टॉल नहीं करना)
1. github.com पर नई private repository बनाएँ.
2. इस फोल्डर की सारी फाइलें (छिपे हुए `.github` फोल्डर समेत) repository में अपलोड करें.
3. Actions टैब खोलें, "Build APK" पूरा होने दें (3-5 मिनट).
4. उस run के नीचे Artifacts से `RideReader-apk` डाउनलोड करें, ZIP खोलकर `app-debug.apk` फोन में डालें.

## Android Studio से बनाना
फोल्डर Android Studio में खोलें, फोन USB से जोड़ें, Run दबाएँ.

## फोन में सेटअप
1. APK इंस्टॉल करें ("Install anyway" आ सकता है).
2. ऐप खोलकर "Accessibility सेटिंग खोलें" दबाएँ, Ride Reader चालू करें.
   (कुछ फोन में पहले ऐप की जानकारी से "Restricted settings" की अनुमति देनी पड़ती है.)
3. एरिया भरें, "सेव करें", फिर "आवाज़ टेस्ट करें".

## ध्यान दें
- ऐप सिर्फ़ उसी स्क्रीन को पढ़ती है जिसके package नाम में "rapido" हो.
- अगर बोलना शुरू न हो, तो Rapido पर राइड आने पर स्क्रीनशॉट भेजें, पार्सर उसी हिसाब से ठीक होगा.
